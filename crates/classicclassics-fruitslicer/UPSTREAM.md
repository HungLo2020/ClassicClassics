# FruitSlicer import

Source: https://github.com/HungLo2020/FruitSlicer
Commit: `2a69fa7f574133fdba9e31da6472ea9ee5283bba`

This is an owned source import, maintained in Classic Classics from here forward.
The original repository is unchanged. Desktop/window/device/persistence hosts are
omitted; `adapter.rs` connects the original deterministic simulation, renderer and
retained `quasar-ui` menus to the collection. Source changes are limited to the
collection's Quasar asset mount, snapshot presentation state and host integration.
Original generated artwork, font, music, effects and regression fixtures are retained.
